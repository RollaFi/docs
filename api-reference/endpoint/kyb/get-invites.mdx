---
title: 'Get Invite'
openapi: 'GET /kyb/invites'
---

Retrieve the KYB invite information for your business.

## Example Request

```bash
curl -X GET "https://api.rolla.xyz/api/v1/external/kyb/invites" \
  -H "X-API-Key: your_api_key_here"
```

## Example Response

```json
{
  "status": 200,
  "message": "Invite retrieved successfully",
  "success": true,
  "data": {
    "id": "69c68e7d-e989-4c75-8b77-c8381467ecf7",
    "name": "Acme Corp Ltd",
    "email": "contact@acmecorp.com",
    "entity_type": "limited_company",
    "status": "completed",
    "usd_only": false,
    "expires_at": null,
    "created_at": "2024-01-10T08:00:00.000Z",
    "updated_at": "2024-01-10T08:00:00.000Z"
  }
}
```

## Status Values

| Status | Meaning |
|--------|---------|
| `active` | Invite created, KYB not yet started |
| `started` | KYB application is in progress |
| `completed` | KYB submitted and approved — business is fully active |
