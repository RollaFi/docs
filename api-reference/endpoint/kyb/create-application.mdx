---
title: 'Create Application'
openapi: 'POST /kyb'
---

Create an empty KYB application for your account. The application is always created against the API key's own account (or, for a tenant key sending `X-Account-Id`, the account named in that header).

<Warning>
  This endpoint takes no request body. Any JSON you send is ignored: the application comes back as an empty `draft` at step 1. Fill it in with [Update Application](/api-reference/endpoint/kyb/update-application).
</Warning>

<Note>
  You rarely need to call this. Every account gets an application the first time [Get Application](/api-reference/endpoint/kyb/get-application) is called, so `GET /kyb` followed by `PUT /kyb` is the usual path. Calling this endpoint for an account that already has an application creates a second, empty one.
</Note>

## Example Request

```bash
curl -X POST "https://api.rolla.xyz/api/v1/external/kyb" \
  -H "X-API-Key: your_api_key_here"
```

## Errors

| Status | Cause |
|--------|-------|
| `401` | API key missing, invalid or inactive |
| `403` | API access is disabled for the account, or the account is restricted (`code: ACCOUNT_RESTRICTED`) |
| `500` | `Failed to create application` |
