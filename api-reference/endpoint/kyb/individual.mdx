---
title: 'Get Individual Application'
openapi: 'GET /kyb/individual'
---

Retrieve the onboarding application for an individual account, together with its uploaded documents.

## Example Request

```bash
curl -X GET "https://api.rolla.xyz/api/v1/external/kyb/individual" \
  -H "X-API-Key: your_api_key_here"
```

<Note>
  This endpoint answers only for accounts whose `entity_type` is `individual`. A business account has no individual application and gets a `404`; read [Get Application](/api-reference/endpoint/kyb/get-application) instead. The business-shaped columns (`business_info`, `related_persons`, ...) are present on the row and stay `null`.
</Note>

## Errors

| Status | Cause |
|--------|-------|
| `401` | API key missing, invalid or inactive |
| `404` | `Application not found` — the account is not an individual account, or has no application yet |
| `500` | The application could not be loaded |
