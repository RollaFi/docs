---
title: 'Upload Document'
openapi: 'POST /kyb/documents'
---

Upload a document for a KYB application. The endpoint takes `multipart/form-data` with the file and its metadata, and the application must belong to your account.

## Example Request

```bash
curl -X POST "https://api.rolla.xyz/api/v1/external/kyb/documents" \
  -H "X-API-Key: your_api_key_here" \
  -F "file=@/path/to/certificate-of-incorporation.pdf" \
  -F "applicationId=3f0c2a1e-7b64-4d2e-9a58-1c9f4b7e2d10" \
  -F "documentType=certificate_of_incorporation"
```

## Form Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `file` | file | Yes | The document to upload. Up to 50MB |
| `applicationId` | string | Yes | KYB application ID |
| `documentType` | string | Yes | One of the document types below |
| `relatedPersonKey` | string | No | The `id` of a related person, when the document belongs to that director or beneficial owner |

## Document types

`certificate_of_incorporation`, `articles_of_association`, `proof_of_address`, `source_of_wealth_doc`, `director_register`, `shareholder_register`, `proof_of_tax_id`, `bank_statement`, `wolfsberg_questionnaire`, `msb_flow_form`, `flow_of_funds_diagram`, `aml_policy_procedures`, `ach_procedures`, `wire_procedures`, `customer_complaint_procedures`, `prohibited_jurisdictions_industries`.

<Warning>
  One document is kept per type. Uploading the same `documentType` again (for the same related person, or for the business when `relatedPersonKey` is omitted) deletes the file already stored under it.
</Warning>

<Note>
  Use `relatedPersonKey` for documents that belong to a specific director or beneficial owner (ID document, proof of address). Those files are stored under `<applicationId>/related-persons/<relatedPersonKey>/<documentType>/`, which is how you tell them apart in the `documents` array.
</Note>

## Errors

| Status | Cause |
|--------|-------|
| `400` | `No file uploaded`, `Application ID is required` or `Document type is required` |
| `401` | API key missing, invalid or inactive |
| `403` | The application belongs to another account |
| `404` | `Application not found` |
| `500` | The file could not be stored (`Failed to upload file to storage`) |
