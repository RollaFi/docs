---
title: 'Get Application'
openapi: 'GET /kyb'
---

Retrieve the KYB (Know Your Business) application for your business, including business information, address, contact details, and verification status.

## Example Request

```bash
curl -X GET "https://api.rolla.xyz/api/v1/external/kyb" \
  -H "X-API-Key: your_api_key_here"
```

### Application Statuses

| Status | Description |
|--------|-------------|
| `draft` | Application is incomplete and can be edited |
| `submitted` | Application has been submitted for review |
| `approved` | Application has been approved |
| `rejected` | Application has been rejected |
| `changes_requested` | Changes have been requested before approval |
