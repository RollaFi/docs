---
title: 'Get Application'
openapi: 'GET /kyb'
---

Retrieve the KYB (Know Your Business) application for your account, including business information, address, contact details, declared related persons and review status.

The application is always the one belonging to the API key's own account (or, for a tenant key sending `X-Account-Id`, the account named in that header). If the account has no application row yet, an empty `draft` one is created and returned.

## Example Request

```bash
curl -X GET "https://api.rolla.xyz/api/v1/external/kyb" \
  -H "X-API-Key: your_api_key_here"
```

### Application Statuses

| Status | Description |
|--------|-------------|
| `draft` | Application is incomplete and can be edited |
| `submitted` | Application has been submitted for review |
| `approved` | Application has been approved |
| `rejected` | Application has been rejected. `rejection_reason` carries the reason |
| `changes_requested` | A reviewer asked for changes. `change_request_note` carries the summary and `flagged_fields` names the fields |

An account whose application has been deactivated, blacklisted or deleted cannot call the API at all: the key is refused with `403` (`code: ACCOUNT_RESTRICTED`) or `401` (`code: ACCOUNT_DOES_NOT_EXIST`) before the request reaches this endpoint.

### Flagged fields

When a reviewer requests changes, `flagged_fields` lists each field they flagged. Resolution is recomputed on every read, so a field you have since edited comes back with `resolved: true`, and one that no longer applies with `not_applicable: true`.

```json
{
  "key": "business_info.registrationNumber",
  "label": "Registration number",
  "section": "business_info",
  "feedback": "This does not match the certificate of incorporation",
  "value_snapshot": "RC-1234567",
  "flagged_at": "2026-09-10T14:22:00.000Z",
  "resolved": false
}
```

## Errors

| Status | Cause |
|--------|-------|
| `401` | API key missing, invalid or inactive |
| `403` | API access is disabled for the account, or the account is restricted (`code: ACCOUNT_RESTRICTED`) |
| `500` | `Failed to load application` |
