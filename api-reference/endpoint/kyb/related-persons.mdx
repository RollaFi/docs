---
title: 'Get Related Persons'
openapi: 'GET /kyb/related-persons'
---

List the related persons (directors and beneficial owners) declared on your KYB application. This is a name-and-role summary; the full details of each person are on the application itself.

## Example Request

```bash
curl -X GET "https://api.rolla.xyz/api/v1/external/kyb/related-persons" \
  -H "X-API-Key: your_api_key_here"
```

## Example Response

```json
{
  "status": 200,
  "message": "Related persons retrieved successfully",
  "success": true,
  "relatedPersons": [
    {
      "id": "b7e1f4c2-3a58-4d90-8c21-9e4f6a0b5d73",
      "firstName": "John",
      "lastName": "Doe",
      "fullName": "John Doe",
      "roles": ["Director", "Beneficial Owner"]
    }
  ]
}
```

<Warning>
  `relatedPersons` sits at the top level of the response, not under `data`. An account with no declared persons gets an empty array.
</Warning>

<Info>
  Only `id`, `firstName`, `lastName`, `fullName` and `roles` come back here. For contact details, address, ownership percentage and identifiers, read `related_persons` on [Get Application](/api-reference/endpoint/kyb/get-application); to add or change a person, send the whole array to [Update Application](/api-reference/endpoint/kyb/update-application). Anyone holding 25% or more must be declared as a beneficial owner.
</Info>

## Errors

| Status | Cause |
|--------|-------|
| `401` | API key missing, invalid or inactive |
| `500` | The related persons could not be loaded |
