---
title: 'Create Referral Link'
openapi: 'POST /broker/referral-link'
---

Generate a new referral link for your business.

<Warning>
  **Broker activation is required.** Broker accounts are activated by the Rolla admin team — you cannot activate a broker account yourself through the API. Once your business has been activated as a broker by Rolla, all broker endpoints become available. Until then, all requests will return a `403 Forbidden` error. Contact [support@rolla.xyz](mailto:support@rolla.xyz) to request broker activation.
</Warning>

## Example Request

```bash
curl -X POST "https://api-staging.rolla.xyz/api/v1/external/broker/referral-link" \
  -H "X-API-Key: your_api_key_here"
```

## Example Response

```json
{
  "success": true,
  "message": "Referral link created successfully",
  "data": {
    "code": "REF-ABCD1234",
    "inviteUrl": "https://app-staging.rolla.xyz/register?code=REF-ABCD1234"
  }
}
```

<Info>
  Share the `inviteUrl` with businesses you want to refer. When they register using this link, they will be linked to your broker account.
</Info>
