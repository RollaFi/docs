---
title: 'Get Referral Link'
openapi: 'GET /broker/referral-link'
---

Retrieve your existing referral link. Your business must be activated as a broker to use this endpoint.

## Example Request

```bash
curl -X GET "https://api.rolla.xyz/api/v1/external/broker/referral-link" \
  -H "X-API-Key: your_api_key_here"
```

## Example Response

```json
{
  "success": true,
  "message": "Referral link retrieved successfully",
  "data": {
    "code": "REF-ABCD1234",
    "inviteUrl": "https://app.rolla.xyz/register?code=REF-ABCD1234"
  }
}
```

<Note>
  All broker endpoints require your business to be activated as a broker. A `403 Forbidden` error is returned if your business is not activated.
</Note>
