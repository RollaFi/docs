---
title: 'Get Referred Businesses'
openapi: 'GET /broker/referred-businesses'
---

Retrieve a paginated list of businesses you have referred. Filter by referral status.

## Example Request

```bash
curl -X GET "https://api.rolla.xyz/api/v1/external/broker/referred-businesses?page=1&pageSize=20&status=approved" \
  -H "X-API-Key: your_api_key_here"
```

## Query Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `page` | integer | Page number (default: 1) |
| `pageSize` | integer | Results per page (default: 20, max: 100) |
| `status` | string | Filter by status: `started`, `completed`, `created`, `approved` |

## Example Response

```json
{
  "success": true,
  "message": "Referred businesses retrieved successfully",
  "data": {
    "businesses": [
      {
        "id": "d4e5f6a7-b8c9-0123-defg-456789012345",
        "businessName": "Acme Corp Ltd",
        "email": "contact@acmecorp.com",
        "status": "approved",
        "created_at": "2024-01-15T10:30:00.000Z"
      }
    ],
    "pagination": {
      "page": 1,
      "pageSize": 20,
      "total": 15
    }
  }
}
```

<Tip>
  The `approved` status means the referred business has completed KYB verification and is active. You will start earning commissions from their transactions.
</Tip>
