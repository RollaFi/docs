---
title: 'Update Business Details'
openapi: 'PUT /accounts/{accountId}/business'
---

Updates the application of a business account. Each section you send (`business_info`, `business_address`, `contact_info`, `banking_info`) is merged into the stored application, so you can save progress incrementally — one section per call or everything at once.

## Mandatory and optional fields

<Note>
  **No individual field is mandatory in this request.** Every section is merged into the
  stored application, so a call carrying one field is as valid as a call carrying all of
  them — that is what lets you save progress as your customer fills your form. The only
  rule is that at least one section must be present.

  Mandatory below means **required before the application can be submitted**. Nothing here
  is enforced until you call [Submit Application](/api-reference/endpoint/accounts/submit).
</Note>

### `business_info`

| Field | | Notes |
|---|---|---|
| `legalName` | **Mandatory** | The registered legal name |
| `businessType` | **Mandatory** | e.g. `Limited Liability Company` |
| `incorporationDate` | **Mandatory** | `YYYY-MM-DD` |
| `incorporationCountry` | **Mandatory** | ISO-2 country code |
| `registrationNumber` | **Mandatory** | Company registration number |
| `taxId` | **Mandatory** | Tax identification or business-licence number |
| `description` | **Mandatory** | 10–1000 characters |
| `monthlyVolume` | **Mandatory** | Digits only, greater than 0 |
| `annualRevenue` | **Mandatory** | Digits only, greater than 0 |
| `primaryFundingSource` | **Mandatory** | e.g. `Business Revenue` |
| `website` | **Mandatory** | Valid URL, including the scheme |
| `tradingName` | Optional | The name the business trades under, when it differs from the legal name. We use the legal name when it is absent |

### `business_address`

| Field | | Notes |
|---|---|---|
| `street` | **Mandatory** | Max 200 characters |
| `city` | **Mandatory** | |
| `state` | **Mandatory** | State, province or region |
| `postalCode` | **Mandatory** | 3–10 characters |
| `country` | **Mandatory** | ISO-2 country code |

### `contact_info`

| Field | | Notes |
|---|---|---|
| `email` | **Mandatory** | |
| `phone` | **Mandatory** | International format, e.g. `+13025550123` |

### `banking_info`

Optional in full. Send it only if you hold the customer's existing bank details; it is not
part of the submit gate.

`bankName`, `accountNumber`, `routingNumber`, `accountType` (`checking` or `savings`), `currency`.

### Documents

All six are mandatory before submission, uploaded via [Upload Document](/api-reference/endpoint/accounts/upload-document):
`certificate_of_incorporation`, `articles_of_association`, `proof_of_address`,
`director_register`, `shareholder_register`, `bank_statement`.

<Tip>
  [Get Requirements](/api-reference/endpoint/accounts/requirements) is the live answer to
  "what is still outstanding" — its `missingFields` and `missingDocuments` arrays name exactly
  what is blocking submission, so you never have to reconcile this table by hand.
</Tip>

<Info>
  Every **beneficial owner / director** must complete identity verification (Sumsub **GREEN**) before the application can be submitted. Add them via [Add Related Person](/api-reference/endpoint/accounts/add-related-person) and send each their KYC link.
</Info>

<Tip>
  **`taxId`** — for a business, use the company's **tax identification / business-license (registration) number**.
</Tip>

## Example Request

```bash
curl -X PUT "https://api.rolla.xyz/api/v1/external/accounts/eec3cbed-79d8-4370-87a0-b6be9e287337/business" \
  -H "X-API-Key: your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "business_info": {
      "legalName": "Beta Logistics LLC",
      "businessType": "Limited Liability Company",
      "incorporationDate": "2020-03-01",
      "incorporationCountry": "US",
      "registrationNumber": "LLC-123987",
      "taxId": "98-7654321",
      "description": "Freight and logistics services across West Africa",
      "monthlyVolume": "100000",
      "annualRevenue": "1200000",
      "primaryFundingSource": "Business Revenue",
      "website": "https://betalogistics.com"
    },
    "business_address": {
      "street": "77 Commerce Ave",
      "city": "Wilmington",
      "state": "DE",
      "postalCode": "19801",
      "country": "US"
    },
    "contact_info": {
      "email": "ops@betalogistics.com",
      "phone": "+13025550123"
    }
  }'
```

## Key Behaviours

<Info>
  Sections are **merged**, not replaced: fields you omit keep their stored values.
</Info>

<Warning>
  Applications can no longer be edited once their status is `submitted` or `approved`. If the review team requests changes, the application becomes editable again.
</Warning>
