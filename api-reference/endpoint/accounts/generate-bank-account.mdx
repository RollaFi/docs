---
title: 'Generate USD Account (Sandbox)'
openapi: 'POST /accounts/{accountId}/bank-accounts/generate'
---

Creates the USD account once its details have been [submitted](/api-reference/endpoint/accounts/submit-bank-account) and passed. Sends the [`account.virtual_account.created`](/api-reference/webhooks/events) webhook.

<Warning>
  **Sandbox only.** Returns `404` in production.
</Warning>

```bash
curl -X POST "https://api-staging.rolla.xyz/api/v1/external/accounts/{accountId}/bank-accounts/generate" \
  -H "X-API-Key: your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{ "currency": "USD" }'
```

## Response

```json
{
  "status": 201,
  "success": true,
  "data": {
    "status": "issued",
    "bankAccount": {
      "id": "a572f509-f16b-47bc-aa6f-cd875db581ea",
      "currency": "USD",
      "bankName": "Portage Bank",
      "accountNumber": "5a8886a6-8012-4311-835c-50d68ccd1f31",
      "accountName": "Amara Okafor",
      "routingNumber": "125109064",
      "swiftCode": "ROUTUS22XXX",
      "status": "active"
    }
  }
}
```

Calling it again returns `200` with `status: "already_exists"` and the same account.

## Errors

| Status | Code | When |
|--------|------|------|
| `400` | — | The body has anything other than `currency: "USD"`. |
| `409` | `ONBOARDING_NOT_SUBMITTED` | The details have not been submitted yet. |
| `409` | `PROVIDER_REVIEW_PENDING` | The details have not passed yet. Submit again. |
