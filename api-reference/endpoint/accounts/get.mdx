---
title: 'Get Account'
openapi: 'GET /accounts/{accountId}'
---

Retrieves a single account with its full KYB/KYC application and uploaded documents. Use this to track an application's status after submission.

## Example Request

```bash
curl -X GET "https://api.rolla.xyz/api/v1/external/accounts/b6075be0-f1d0-451f-a468-3e94563101d2" \
  -H "X-API-Key: your_api_key_here"
```

<Note>
  `application` is the stored application row, so its keys are snake_case and the sections that
  do not apply to the account's `entity_type` come back as `null` — a business account carries
  `business_info`, `business_address`, `contact_info`, `banking_info` and `related_persons`, an
  individual account carries `individual_info`. Documents are listed for the whole application;
  a related person's documents carry their id in `file_path`.
</Note>

<Tip>
  Application `status` moves from `draft` → `submitted` → `approved` (or `changes_requested` / `rejected`). When changes are requested, the application becomes editable again and `change_request_note` explains what needs fixing.
</Tip>
