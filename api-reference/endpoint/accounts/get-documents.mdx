---
title: 'List Documents'
openapi: 'GET /accounts/{accountId}/documents'
---

Lists every document uploaded to an account's application, including the documents attached to its related persons. Optionally filter by `documentType`.

## Example Request

```bash
curl -X GET "https://api.rolla.xyz/api/v1/external/accounts/eec3cbed-79d8-4370-87a0-b6be9e287337/documents" \
  -H "X-API-Key: your_api_key_here"
```

## Query Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `documentType` | string | No | Return only documents of this type. Must be one of the [document types](/api-reference/endpoint/accounts/upload-document#document-types) |

<Note>
  The listing is not filtered by related person, and there is no `relatedPersonId` field on a document. A document attached to a person is recognised by `related-persons/<relatedPersonId>` in its `file_path`.
</Note>
