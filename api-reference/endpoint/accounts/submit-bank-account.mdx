---
title: 'Submit USD Account Details (Sandbox)'
openapi: 'POST /accounts/{accountId}/bank-accounts/submit'
---

Sends a requested USD account's details to the banking partner's sandbox. When they pass, [generate the account](/api-reference/endpoint/accounts/generate-bank-account).

<Warning>
  **Sandbox only.** Returns `404` in production, where the Rolla team handles this step.
</Warning>

## Request Body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `currency` | string | Yes | `"USD"`. |
| `accountData` | object | No | Corrections to the details in `prefilled` from [Bank Account Requirements](/api-reference/endpoint/accounts/bank-account-requirements), in the same shape. |

```bash
curl -X POST "https://api-staging.rolla.xyz/api/v1/external/accounts/{accountId}/bank-accounts/submit" \
  -H "X-API-Key: your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{ "currency": "USD", "accountData": { "onboardingDetails": { "taxNumber": "90123456789" } } }'
```

## Response

```json
{
  "status": 200,
  "success": true,
  "data": {
    "status": "submitted",
    "requestId": "70ad758f-2a1f-429d-a933-d546c1c27a61",
    "onboardingState": "entity_finalized",
    "readyToGenerate": true
  }
}
```

If `readyToGenerate` is `false`, call again after a few seconds.

## Errors

| Status | Code | When |
|--------|------|------|
| `409` | `APPLICATION_NOT_APPROVED` | The account is not approved. |
| `409` | `NO_OPEN_REQUEST` | No USD account has been [requested](/api-reference/endpoint/accounts/issue-bank-account). |
| `422` | — | The banking partner rejected the details. `errors` says which field; correct it and submit again. |
