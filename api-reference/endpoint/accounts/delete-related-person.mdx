---
title: 'Delete Related Person'
openapi: 'DELETE /accounts/{accountId}/related-persons/{personId}'
---

Removes a related person from a business account's application, along with any documents uploaded for them.

## Example Request

```bash
curl -X DELETE "https://api.rolla.xyz/api/v1/external/accounts/eec3cbed-79d8-4370-87a0-b6be9e287337/related-persons/a3d4f21e-f499-488f-8508-43228dfea485" \
  -H "X-API-Key: your_api_key_here"
```

## Example Response

```json
{
  "success": true,
  "message": "Related person deleted successfully",
  "data": {
    "success": true
  }
}
```
