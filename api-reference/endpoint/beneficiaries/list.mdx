---
title: 'List Beneficiaries'
openapi: 'GET /beneficiaries'
---

Retrieve a paginated list of saved beneficiaries for your business. Filter by currency or search by name and account number.

## Example Request

```bash
curl -X GET "https://api.rolla.xyz/api/v1/external/beneficiaries?page=1&pageSize=20&currency=NGN" \
  -H "X-API-Key: your_api_key_here"
```

## Query Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `page` | integer | Page number (default: 1, minimum: 1) |
| `pageSize` | integer | Results per page (default: 20, max: 100) |
| `currency` | string | Filter by currency code (e.g. `NGN`, `USD`). Comma-separate to match several (`NGN,USD`). `rolla_transfer` beneficiaries are always included regardless of currency. |
| `search` | string | Case-insensitive match on label, account name, email, contact person, account number, address or wallet address |
| `type` | string | `rolla` returns only `rolla_transfer` beneficiaries; `external` returns everything else |
| `wallet_chain` | string | Filter crypto beneficiaries by network slug (e.g. `base`) |

An invalid query value (for example `pageSize=500`) returns `400` with `"message": "Validation failed"` and an `errors` array.

## Example Response

Results are ordered newest first. Each beneficiary carries only its populated fields, except `withdrawal_method`, which is always present and is `null` when no rail was set.

```json
{
  "status": 200,
  "message": "Beneficiaries retrieved successfully",
  "success": true,
  "data": {
    "beneficiaries": [
      {
        "id": "c3d4e5f6-a7b8-9012-cdef-123456789012",
        "account_name": "JOHN DOE",
        "currency": "NGN",
        "email": "john@example.com",
        "withdrawal_method": null,
        "label": "Office rent",
        "account_number": "0123456789",
        "bank_name": "Access Bank",
        "bank_code": "000014"
      }
    ],
    "totalCount": 5,
    "page": 1,
    "pageSize": 20,
    "totalPages": 1
  }
}
```

<Tip>
  Use the `search` parameter to quickly find beneficiaries by name or account number without needing to paginate through all results.
</Tip>
