---
title: 'Remove Team Member'
openapi: 'DELETE /teams/members/{userId}'
---

Remove a team member from your business. The member will lose access immediately.

## Example Request

```bash
curl -X DELETE "https://api-staging.rolla.xyz/api/v1/external/teams/members/a1b2c3d4-e5f6-7890-abcd-ef1234567890" \
  -H "X-API-Key: your_api_key_here"
```

## Example Response

```json
{
  "status": 200,
  "success": true,
  "message": "Team member removed successfully",
  "data": {
    "userId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890"
  }
}
```

<Warning>
  You cannot remove yourself or the business owner. Attempting to do so will return a `400 Bad Request` error.
</Warning>
