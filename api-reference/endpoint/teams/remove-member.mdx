---
title: 'Remove Team Member'
openapi: 'DELETE /teams/members/{userId}'
---

Remove a team member from your business. The member will lose access immediately.

## Example Request

```bash
curl -X DELETE "https://api.rolla.xyz/api/v1/external/teams/members/a1b2c3d4-e5f6-7890-abcd-ef1234567890" \
  -H "X-API-Key: your_api_key_here"
```

## Example Response

```json
{
  "status": 200,
  "message": "Team member removed successfully",
  "success": true,
  "data": {
    "userId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890"
  }
}
```

<Warning>
  The business owner cannot be removed. Attempting it returns `400 Bad Request` with the message `Cannot remove the business owner from the business`. A user who is not a member of your business returns `404 Not Found`.
</Warning>
