---
title: 'Account Lookup'
openapi: 'POST /lookup'
---

Validate a bank account number and retrieve the account holder's name. This is useful for confirming beneficiary details before initiating a payout.

## Example Request

```bash
curl -X POST "https://api.rolla.xyz/api/v1/external/lookup" \
  -H "X-API-Key: your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "bankCode": "000014",
    "accountNumber": "0123456789"
  }'
```

## Example Response

```json
{
  "status": true,
  "message": "Account details retrieved successfully",
  "data": {
    "data": {
      "accountNumber": "0123456789",
      "accountName": "JOHN DOE",
      "bankCode": "000014",
      "bankName": "Access Bank"
    }
  }
}
```

<Warning>
  Always verify the account name with your user before initiating a payout. Incorrect details may result in failed or misdirected payments.
</Warning>
