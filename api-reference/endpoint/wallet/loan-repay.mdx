---
title: 'Repay Loan'
openapi: 'POST /wallet/loans/repay'
---

Repay a loan from a source wallet. `amount` is a whole number of the smallest unit of the loan currency (kobo for NGN, cents for USD).

## Example Request

```bash
curl -X POST "https://api.rolla.xyz/api/v1/external/wallet/loans/repay" \
  -H "X-API-Key: your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "loanAccountId": "d4e5f6a7-b8c9-4012-9def-456789012345",
    "sourceWalletId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    "amount": 25000,
    "description": "Partial loan repayment"
  }'
```

<Note>
  `transaction` and `entries` are the raw ledger rows, at the top level rather than under `data`. They are read back before the entries are posted, so both report `"pending"` even though the repayment has already settled. The ledger stores amounts as 64-bit integers, so `fee_amount`, `source_amount` and `destination_amount` arrive as strings of smallest units. Unused ledger columns (for example `approved_at`, `transfer_direction`) are present and `null`.
</Note>

<Info>
  You can make partial repayments. The source wallet must have sufficient `balance.availableBalance` to cover the repayment amount.
</Info>
