---
title: 'Get Statement'
openapi: 'GET /wallet/statement'
---

Retrieve a wallet statement summary including opening/closing balances, totals, and the transactions behind them for a given period.

## Query Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `currency` | string | Yes | Currency of the account to draw the statement for (e.g. `NGN`, `USD`) |
| `startDate` | string | Yes | Inclusive start of the period (`YYYY-MM-DD`) |
| `endDate` | string | Yes | Inclusive end of the period (`YYYY-MM-DD`) |
| `accountType` | string | No | `wallet` or `loan`. Omitted, wallets and credit lines of that currency are reported together. |

## Example Request

```bash
curl -X GET "https://api.rolla.xyz/api/v1/external/wallet/statement?currency=NGN&startDate=2026-01-01&endDate=2026-01-31&accountType=wallet" \
  -H "X-API-Key: your_api_key_here"
```

## Example Response

```json
{
  "status": 200,
  "message": "Statement data retrieved successfully",
  "success": true,
  "data": {
    "businessName": "Acme Corp Ltd",
    "currency": "NGN",
    "openingBalance": 500000,
    "closingBalance": 1000000,
    "totalCredits": 750000,
    "totalDebits": 250000,
    "transactions": [
      {
        "id": "3c90c3cc-0d44-4b50-8888-8dd25736052a",
        "transaction_type": "deposit",
        "status": "completed",
        "description": "Wallet funding",
        "external_reference": "ref_abc123",
        "fee_amount": 0,
        "source_amount": 750000,
        "destination_amount": 750000,
        "source_currency": "NGN",
        "destination_currency": "NGN",
        "created_at": "2026-01-10T09:15:00.000Z",
        "updated_at": "2026-01-10T09:15:30.000Z"
      }
    ]
  }
}
```

Balances, totals and amounts are all in **minor units** — `500000` is ₦5,000.00. The
transactions are listed oldest first, in the order the statement prints.

<Note>
  A statement row reports `transaction_type` as the movement affected **this** account, so a row
  can read `received` or `sent` where the underlying transaction is a withdrawal, fee or deposit.
  Read `id` if you need to tie a row back to the transaction itself.
</Note>

## Error Response

A missing `currency`, or a currency you hold no account in, returns `400`:

```json
{
  "status": 400,
  "message": "Currency is required"
}
```

<Tip>
  Use this endpoint to generate periodic account statements for your records or for compliance reporting.
</Tip>
