---
title: 'Draw Loan Funds'
openapi: 'POST /wallet/loans/draw'
---

Draw funds from a loan account into a destination wallet. `amount` is a whole number of the smallest unit of the loan currency (kobo for NGN, cents for USD).

## Example Request

```bash
curl -X POST "https://api.rolla.xyz/api/v1/external/wallet/loans/draw" \
  -H "X-API-Key: your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "loanAccountId": "d4e5f6a7-b8c9-4012-9def-456789012345",
    "destinationWalletId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    "amount": 50000,
    "description": "Draw funds for operations"
  }'
```

<Note>
  `transaction` and `entries` are the raw ledger rows, at the top level rather than under `data`. They are read back before the entries are posted, so both report `"pending"` even though the draw has already settled: read the wallet or the transaction back if you need the final state. The ledger stores amounts as 64-bit integers, so `fee_amount`, `source_amount` and `destination_amount` arrive as strings of smallest units. Unused ledger columns (for example `approved_at`, `transfer_direction`) are present and `null`.
</Note>

<Warning>
  The draw cannot take the outstanding balance past the loan account's `credit_limit`. Use [`GET /wallet/loans`](/api-reference/endpoint/wallet/loans) to check the limit and the amount already drawn before drawing.
</Warning>
