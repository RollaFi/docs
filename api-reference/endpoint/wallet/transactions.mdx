---
title: 'List Wallet Transactions'
openapi: 'GET /wallet/transactions'
---

Retrieve a paginated list of wallet transactions, newest first, with optional filtering by currency, type, status, date range, and search term.

## Example Request

```bash
curl -X GET "https://api.rolla.xyz/api/v1/external/wallet/transactions?currency=NGN&status=completed&page=1&pageSize=20" \
  -H "X-API-Key: your_api_key_here"
```

## Query Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `currency` | string | Filter by **source** currency code (e.g. `NGN`, `USD`), so a swap is listed under the currency it was sold from rather than under both |
| `transactionType` | string | Filter by type: `deposit`, `withdrawal`, `swap`, `card_funding`, `payin`, `fee` |
| `status` | string | Filter by status: `pending`, `completed`, `failed`, `rejected`, `sent`, `negotiating`, `cancelled` |
| `page` | integer | Page number, starting at 1 (default: 1) |
| `pageSize` | integer | Results per page (default: 20, max: 100) |
| `startDate` | string | Inclusive start (`YYYY-MM-DD`) |
| `endDate` | string | Inclusive end (`YYYY-MM-DD`) |
| `search` | string | Case-insensitive substring match on `external_reference` |

Transactions with status `failed` are left out unless you ask for them with `status=failed`.
`status=completed` also returns pending transactions our operations team has already claimed,
which are reported as completed; `status=pending` excludes them.

Amounts are in **minor units** — `500000` is ₦5,000.00. Fields that do not apply to a
transaction are **omitted** rather than returned as `null`: `exchange_rate` appears on swaps
only, `virtual_account`, `payer` and `payment_rail` on deposits only, and `uetr` only once a
cross-border payout has been assigned one.

<Tip>
  Use date range filters to export transaction data for specific periods. Combine with the `status` filter to find failed transactions that may need to be retried.
</Tip>
