---
title: 'List Wallets'
openapi: 'GET /wallet/wallets'
---

Retrieve all wallets for your business, including balances and the payment accounts that receive funds into each wallet. Loan accounts are not returned here; use [`GET /wallet/loans`](/api-reference/endpoint/wallet/loans) for those.

## Example Request

```bash
curl -X GET "https://api.rolla.xyz/api/v1/external/wallet/wallets" \
  -H "X-API-Key: your_api_key_here"
```

<Tip>
  Use `balance.availableBalance` (not `balance.postedBalance`) when checking if you have sufficient funds for a withdrawal. `postedBalance` includes pending debits that haven't settled yet, and `availableBalance` is already net of `lienAmount`, the portion reserved and unavailable for withdrawal.
</Tip>

<Note>
  Each wallet includes a `virtualAccounts` array containing the payment accounts used to receive funds into that wallet (e.g. bank account details for NGN, wallet addresses for crypto).
</Note>
