---
title: 'List Customer Virtual Accounts'
openapi: 'GET /wallet/virtual-accounts/customers'
---

List the permanent per-end-user virtual accounts you've created for your business. Optionally filter to a single user with `customer_identifier`.

## Example Request

```bash
curl -X GET "https://api-staging.rolla.xyz/api/v1/external/wallet/virtual-accounts/customers?customer_identifier=user-12345" \
  -H "X-API-Key: your_api_key_here"
```

## Query Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `customer_identifier` | string | Filter to a single end-user's account. Omit to list all. |

</Note>
