---
title: 'List Virtual Accounts'
openapi: 'GET /wallet/virtual-accounts'
---

Retrieve the active virtual accounts your business can receive payments into. Filter by currency or account type.

## Example Request

```bash
curl -X GET "https://api.rolla.xyz/api/v1/external/wallet/virtual-accounts?currency=NGN&virtualAccountType=static" \
  -H "X-API-Key: your_api_key_here"
```

## Query Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `currency` | string | Filter by currency code, 3 or 4 characters (for example `NGN`, `USD`, `USDT`). Matched case-insensitively. |
| `virtualAccountType` | string | Filter by type: `static` or `dynamic`. Defaults to `static` when omitted, so dynamic accounts are only returned when you ask for them. |

## Example Response

```json
{
  "status": 200,
  "message": "Virtual accounts retrieved successfully",
  "success": true,
  "data": {
    "virtualAccounts": [
      {
        "id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
        "status": "active",
        "virtual_account_type": "static",
        "currency_type": "fiat",
        "bank_name": "Wema Bank",
        "account_number": "9876543210",
        "account_name": "Rolla / Your Business Name"
      }
    ]
  }
}
```

Fields that are empty for an account are left out, so a fiat account carries bank details while a crypto account carries `wallet_address`, `wallet_chain` and `stablecoin_type` instead. USD accounts also carry `routing_number`, `swift_code` and `bank_address`, and a dynamic account carries `expires_at`.

<Info>
  **Static** virtual accounts are permanent and can receive multiple payments. **Dynamic** virtual accounts are created for a specific amount and expire after use.
</Info>
