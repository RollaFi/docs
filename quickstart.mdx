This guide takes you from zero to a completed NGN payout **on your own account**. Along the way you'll touch the four things almost every integration uses: wallets, virtual accounts, beneficiaries, and withdrawals.

<Info>
  Building banking for **your own customers** as an MSB or FI? Do this quickstart first — then the [Platform Quickstart](/platform/quickstart) adds customer onboarding and per-customer scoping on top of everything here.
</Info>

## Prerequisites

- A verified Rolla business account at [app.rolla.xyz](https://app.rolla.xyz)
- Funds — or a plan to deposit some in Step 3

## Step 1: Create an API key

<Steps>
  <Step title="Open the dashboard">
    Log in at [app.rolla.xyz](https://app.rolla.xyz) and go to **Settings → API Keys**.
  </Step>
  <Step title="Create a key">
    Click **Create API Key**, name it, and copy the key. It is shown **once** — store it securely.
  </Step>
  <Step title="Allowlist your server IPs">
    Add your server's IP addresses to the key's allowlist. Reads work without it, but **withdrawals and transfers are rejected unless the key has at least one allowlisted IP** and the request comes from it.
  </Step>
</Steps>

<Warning>
  Keep your API key secret. Never expose it in frontend code or public repositories.
</Warning>

## Step 2: Make your first request

Send the key in the `X-API-Key` header. List your wallets to confirm everything works:

```bash
curl "https://api.rolla.xyz/api/v1/external/wallet/wallets" \
  -H "X-API-Key: your_api_key_here"
```

```json
{
  "status": 200,
  "success": true,
  "message": "Business wallets retrieved successfully",
  "data": {
    "wallets": [
      {
        "currency": "NGN",
        "balance": {
          "availableBalance": 950000,
          "postedBalance": 1000000,
          "pendingBalance": 50000
        }
      }
    ]
  }
}
```

Every successful response carries `status` (the HTTP code), `success: true`, a human-readable `message`, and the payload under `data`. All amounts are in the currency's **smallest unit** — kobo for NGN, cents for USD. See [Amounts & Currencies](/concepts/amounts-and-currencies).

## Step 3: Fund your wallet

Generate a dynamic virtual account and transfer money to it from any Nigerian bank. Rolla credits your NGN wallet when the deposit lands:

```bash
curl -X POST "https://api.rolla.xyz/api/v1/external/wallet/virtual-accounts/generate/dynamic" \
  -H "X-API-Key: your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{ "amount": 500000 }'
```

The response contains a `bank_name` and `account_number` to pay into. `500000` kobo = ₦5,000.

<Info>
  Testing without real money? Sandbox environments expose [Simulate a Deposit](/api-reference/endpoint/wallet/simulate-deposit) to credit your wallet instantly.
</Info>

## Step 4: Create a beneficiary

First resolve the recipient's account so you know the name matches:

```bash
curl -X POST "https://api.rolla.xyz/api/v1/external/lookup" \
  -H "X-API-Key: your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{ "bankCode": "000014", "accountNumber": "0123456789" }'
```

Then save them as a beneficiary (get bank codes from [List Banks](/api-reference/endpoint/banks)):

```bash
curl -X POST "https://api.rolla.xyz/api/v1/external/beneficiaries" \
  -H "X-API-Key: your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "currency": "NGN",
    "label": "Test beneficiary",
    "account_name": "JOHN DOE",
    "account_number": "0123456789",
    "bank_name": "Access Bank",
    "bank_code": "000014"
  }'
```

Copy the `id` from the response.

<Info>
  In a hurry? [Withdraw Funds](/api-reference/endpoint/wallet/withdraw) also accepts `inlineBeneficiary` details directly, so you can skip this step for one-off payouts.
</Info>

## Step 5: Send the payout

```bash
curl -X POST "https://api.rolla.xyz/api/v1/external/wallet/withdraw" \
  -H "X-API-Key: your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 100000,
    "currency": "NGN",
    "beneficiaryId": "BENEFICIARY_ID_FROM_STEP_4",
    "description": "Test payout",
    "externalReference": "your-unique-ref-001"
  }'
```

`100000` kobo = ₦1,000. Fees are deducted from the withdrawal amount by default; want a fee quote first? Call [Get Transaction Fee](/api-reference/endpoint/wallet/fee).

<Warning>
  This request must come from an IP on your key's allowlist (Step 1), or it is rejected with `403`.
</Warning>

The response includes a transaction `id` and a `reference`. The `externalReference` is your own reconciliation handle on the payout — you can [fetch the transaction by it](/api-reference/endpoint/wallet/get-transaction) later. See [Idempotency & Retries](/concepts/idempotency) before retrying failed requests.

## Step 6: Track it

Poll the transaction:

```bash
curl "https://api.rolla.xyz/api/v1/external/wallet/transaction/TRANSACTION_ID" \
  -H "X-API-Key: your_api_key_here"
```

Or — better — configure a [webhook endpoint](/api-reference/webhooks/overview) in the dashboard and receive `transaction.completed` / `transaction.failed` events the moment the payout settles, instead of polling.
